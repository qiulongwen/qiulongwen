## 工具取舍

- 能进 Git 的记录，优先 Markdown
- 临时想法可以乱，**归档时必须有主题 + 标签**
- 新工具默认观察两周，再决定是否进入日常

## 写作节奏

1. 先写结论（三句话内）
2. 再补清单 / 表格
3. 最后才写背景故事（多数时候可以删）

## 方法论备忘

- 同一类问题，第二次出现就抽成模板
- 「以后再整理」≈ 不会整理 → 当场打上主题
