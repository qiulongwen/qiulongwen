## 接口风格

- 资源用名词，动作靠 HTTP Method
- 列表查询参数统一：`page` / `pageSize` / `sort`
- 响应结构固定：`code` · `message` · `data`

## 错误与鉴权

| 类型 | 建议 |
|------|------|
| 参数错误 | 4xx + 可读 message，指出字段 |
| 未登录 / 无权限 | 401 / 403，勿混用 |
| 服务异常 | 5xx，对内打日志，对外不泄细节 |

- Token 放 Header；过期策略与刷新路径写清楚
- 敏感操作二次确认或幂等键

## 数据层提醒

- 读写路径分开想：缓存击穿、空结果缓存
- 迁移脚本可回滚，避免只写「正向」
