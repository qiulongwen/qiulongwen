> 示例笔记。先建立管线心智模型，再碰引擎细节。

## 渲染管线（极简）

1. 顶点数据 → 顶点着色器
2. 图元组装 / 光栅化
3. 片元着色器 → 深度 / 混合 → 帧缓冲

## 坐标与矩阵

- 模型 → 世界 → 观察 → 裁剪 → NDC → 屏幕
- 搞不清「谁乘谁」时，先画一张变换链再写代码
- 近大远小来自投影，不是「随便 scale」

## 调试习惯

- 先画 clearest triangle，再加纹理与光照
- Shader 编译错误读完整日志，不要只看第一行
- 用纯色 / UV 可视化隔离问题在 VS 还是 FS
