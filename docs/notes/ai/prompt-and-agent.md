> 示例笔记。先建立可复用的写法，再扩到评测与工程化。

## Prompt 约定

- **角色**：一句话说清模型在扮演什么
- **目标**：输出要解决什么问题，避免空泛「帮我看看」
- **约束**：格式、长度、禁止项写在同一段
- **示例**：给 1～2 个正例，比堆形容词更稳

## 最小 Agent 流程

1. 理解任务（澄清输入）
2. 选择工具 / 检索
3. 执行并校验结果
4. 失败时回退或追问，而不是硬编

## 常见坑

- 一次 Prompt 塞进过多目标，输出漂移
- 没有验收标准，无法判断「够不够好」
- 把 Agent 当成聊天，而不是有状态的流程
