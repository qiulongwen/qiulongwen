技术知识库更适合「主题 + 标签」而不是时间线博客。

## 为什么选 VitePress

1. **Markdown 优先**：写作成本低，Git 友好
2. **侧边栏成熟**：主题导航天然合适
3. **本地搜索**：标签之外再加一层检索
4. **静态发布**：适合 GitHub Pages

## 本站约定

- 每篇笔记写明 `theme` 与 `tags`
- 首页展示主题与常用标签
- 知识库页支持按主题 / 标签筛选

## 写作建议

- 标题直接说清楚主题
- 正文偏结论与清单，少写空泛铺垫
- 同一主题下保持结构相近，方便回查
